IE213 BACKEND API DOCUMENTATION
Cap nhat theo source code hien tai (routes + controllers)
Base URL: http://localhost:5000/api

=====================================================
0) RESPONSE FORMAT
=====================================================
Thanh cong:
- success: true
- message: string
- data: any
- meta: object (timestamp, requestId, pagination neu co)

That bai:
- success: false
- message: string
- details/error tuy loai loi

=====================================================
1) AUTH APIs
Base: /api/auth
=====================================================

1.1) Dang ky
- Method: POST
- Endpoint: /api/auth/register
- Auth: Public
- Body:
  {
    "name": "Nguyen Van A",
    "email": "a@example.com",
    "password": "123456",
    "phone": "0901234567"   // optional
  }
- Validation:
  - name bat buoc
  - email dung dinh dang
  - password toi thieu 6 ky tu

1.2) Dang nhap
- Method: POST
- Endpoint: /api/auth/login
- Auth: Public
- Body:
  {
    "email": "a@example.com",
    "password": "123456"
  }

1.3) Lay user hien tai
- Method: GET
- Endpoint: /api/auth/me
- Auth: User

1.4) Dang xuat
- Method: POST
- Endpoint: /api/auth/logout
- Auth: User

1.5) Quen mat khau - gui email
- Method: POST
- Endpoint: /api/auth/forgot-password
- Auth: Public
- Body:
  {
    "email": "user@example.com"
  }
- Response:
  {
    "success": true,
    "message": "Email dat lai mat khau da duoc gui"
  }
- Ghi chu:
  - Chi ap dung cho user thuong, khong ap dung cho admin
  - Neu email thuoc admin, API tra ve 403 va khong tao token
  - Khong tra ve thong tin email user thuong co ton tai hay khong (email khong ton tai van tra thong bao thanh cong)
  - Moi email chi giu 1 reset token dang hoat dong (tao moi se xoa token cu)
  - Co rate limit de tranh bi spam (gioi han tren API forgot-password)

1.6) Dat lai mat khau
- Method: POST
- Endpoint: /api/auth/reset-password
- Auth: Public
- Body:
  {
    "token": "reset_token_from_email",
    "newPassword": "12345678"
  }
- Validation:
  - newPassword toi thieu 6 ky tu
- Ghi chu:
  - Chi ap dung cho user thuong, khong ap dung cho admin
  - Token duoc luu trong collection rieng va tu dong het han bang TTL index
  - Sau khi dat lai mat khau thanh cong, token se bi xoa
  - API reset-password khong can email, nen khong tra ve thong tin ton tai email

=====================================================
2) USER APIs
Base: /api/users
=====================================================

2.1) Lay profile
- Method: GET
- Endpoint: /api/users/profile
- Auth: User

2.2) Cap nhat profile
- Method: PUT
- Endpoint: /api/users/profile
- Auth: User
- Body (tat ca optional, nhung phai co it nhat 1 truong hop le):
  {
    "name": "Nguyen Van B",
    "phone": "0911111111",
    "avatar": "https://..."
  }

2.3) Doi mat khau
- Method: PUT
- Endpoint: /api/users/change-password
- Auth: User
- Body:
  {
    "currentPassword": "123456",
    "newPassword": "12345678"
  }

2.4) Them dia chi
- Method: POST
- Endpoint: /api/users/addresses
- Auth: User
- Body:
  {
    "label": "Nha",        // optional
    "address": "123 Nguyen Trai, Q1",
    "isDefault": true        // optional
  }

2.5) Dat dia chi mac dinh
- Method: PUT
- Endpoint: /api/users/addresses/:addressId/set-default
- Auth: User
- Params:
  - addressId: Mongo ObjectId

2.6) Cap nhat dia chi
- Method: PUT
- Endpoint: /api/users/addresses/:addressId
- Auth: User
- Params:
  - addressId: Mongo ObjectId
- Body:
  {
    "label": "Cong ty",
    "address": "Toa nha X",
    "isDefault": false
  }

2.7) Xoa dia chi
- Method: DELETE
- Endpoint: /api/users/addresses/:addressId
- Auth: User
- Params:
  - addressId: Mongo ObjectId

4) PRODUCT APIs
Base: /api/products
=====================================================

4.1) Danh sach product
- Method: GET
- Endpoint: /api/products
- Auth: Public
- Query optional:
  - keyword
  - categoryId
  - brand
  - minPrice
  - maxPrice
  - sort (newest | priceAsc | priceDesc | topRated)
  - page
  - limit

4.2) Product theo slug
- Method: GET
- Endpoint: /api/products/slug/:slug
- Auth: Public

4.3) Danh sach review cua product
- Method: GET
- Endpoint: /api/products/:productId/reviews
- Auth: Public
- Params:
  - productId: Mongo ObjectId
- Query optional:
  - page
  - limit
  - rating

4.4) Tao review cho product
- Method: POST
- Endpoint: /api/products/:productId/reviews
- Auth: User
- Params:
  - productId: Mongo ObjectId
- Body:
  {
    "rating": 5,
    "title": "Rat tot",
    "comment": "San pham dep",
    "images": []
  }

4.5) Product theo id
- Method: GET
- Endpoint: /api/products/:id
- Auth: Public
- Params:
  - id: Mongo ObjectId

4.6) Upload 1 anh product
- Method: POST
- Endpoint: /api/products/upload-image
- Auth: Admin
- Form-data:
  - image: file

4.7) Tao product
- Method: POST
- Endpoint: /api/products
- Auth: Admin
- Body: theo schema Product (name, categoryId, variants, ...)

4.8) Cap nhat product
- Method: PUT
- Endpoint: /api/products/:id
- Auth: Admin
- Params:
  - id: Mongo ObjectId

4.9) Xoa product
- Method: DELETE
- Endpoint: /api/products/:id
- Auth: Admin
- Params:
  - id: Mongo ObjectId
