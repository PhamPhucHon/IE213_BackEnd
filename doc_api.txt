=====================================================
0) RESPONSE FORMAT
=====================================================
Thanh cong:
- success: true
- message: string
- data: any
- meta: object (timestamp, requestId, pagination neu co)

That bai:
- success: false
- message: string
- details/error tuy loai loi

=====================================================
1) AUTH APIs
Base: /api/auth
=====================================================

1.1) Dang ky
- Method: POST
- Endpoint: /api/auth/register
- Auth: Public
- Body:
  {
    "name": "Nguyen Van A",
    "email": "a@example.com",
    "password": "123456",
    "phone": "0901234567"   // optional
  }
- Validation:
  - name bat buoc
  - email dung dinh dang
  - password toi thieu 6 ky tu

1.2) Dang nhap
- Method: POST
- Endpoint: /api/auth/login
- Auth: Public
- Body:
  {
    "email": "a@example.com",
    "password": "123456"
  }
- Response (thanh cong):
  {
    "user": { ... },
    "token": "<access_token>",
    "refreshToken": "<refresh_token>"
  }

1.3) Lay user hien tai
- Method: GET
- Endpoint: /api/auth/me
- Auth: User

1.4) Dang xuat
- Method: POST
- Endpoint: /api/auth/logout
- Auth: User
- Body (optional):
  {
    "refreshToken": "<refresh_token>"
  }
- Ghi chu:
  - Access token (tu header Authorization) se bi blacklist
  - Neu truyen them refreshToken trong body, no cung se bi blacklist luon
  - Nen truyen ca refreshToken de revoke ca hai token mot luc

1.5) Quen mat khau - gui email
- Method: POST
- Endpoint: /api/auth/forgot-password
- Auth: Public
- Body:
  {
    "email": "user@example.com"
  }
- Response:
  {
    "success": true,
    "message": "Email dat lai mat khau da duoc gui"
  }
- Ghi chu:
  - Chi ap dung cho user thuong, khong ap dung cho admin
  - Neu email thuoc admin, API van tra thong bao thanh cong chung va khong tao token
  - Khong tra ve thong tin email user thuong co ton tai hay khong (email khong ton tai van tra thong bao thanh cong)
  - Moi email chi giu 1 reset token dang hoat dong (tao moi se xoa token cu)
  - Co rate limit de tranh bi spam (gioi han tren API forgot-password)

1.6) Dat lai mat khau
- Method: POST
- Endpoint: /api/auth/reset-password
- Auth: Public
- Body:
  {
    "token": "reset_token_from_email",
    "newPassword": "12345678"
  }
- Validation:
  - newPassword toi thieu 6 ky tu
- Ghi chu:
  - Chi ap dung cho user thuong, khong ap dung cho admin
  - Token duoc luu trong collection rieng va tu dong het han bang TTL index
  - Sau khi dat lai mat khau thanh cong, token se bi xoa
  - API reset-password khong can email, nen khong tra ve thong tin ton tai email

1.7) Lam moi access token
- Method: POST
- Endpoint: /api/auth/refresh-token
- Auth: Public
- Body:
  {
    "refreshToken": "<refresh_token_nhan_duoc_khi_login>"
  }
- Response (thanh cong):
  {
    "success": true,
    "message": "Lam moi token thanh cong",
    "data": {
      "token": "<access_token_moi>"
    },
    "meta": { "timestamp": "..." }
  }
- Response (that bai):
  - 400: Thieu refreshToken trong body
  - 401: refreshToken khong hop le, het han, hoac da bi blacklist
- Ghi chu:
  - refreshToken co thoi han dai hon (30d), access token ngan hon (7d)
  - refreshToken dung secret rieng (JWT_REFRESH_SECRET), khong the dung thay access token
  - Sau khi goi /logout voi refreshToken, token do se bi blacklist va khong the refresh nua

2) USER APIs
Base: /api/users
=====================================================

2.1) Lay profile
- Method: GET
- Endpoint: /api/users/profile
- Auth: User

2.2) Cap nhat profile
- Method: PUT
- Endpoint: /api/users/profile
- Auth: User
- Body (tat ca optional, nhung phai co it nhat 1 truong hop le):
  {
    "name": "Nguyen Van B",
    "phone": "0911111111",
    "avatar": "https://..."
  }

2.3) Doi mat khau
- Method: PUT
- Endpoint: /api/users/change-password
- Auth: User
- Body:
  {
    "currentPassword": "123456",
    "newPassword": "12345678"
  }

2.4) Them dia chi
- Method: POST
- Endpoint: /api/users/addresses
- Auth: User
- Body:
  {
    "label": "Nha",        // optional
    "address": "123 Nguyen Trai, Q1",
    "isDefault": true        // optional
  }

2.5) Dat dia chi mac dinh
- Method: PUT
- Endpoint: /api/users/addresses/:addressId/set-default
- Auth: User
- Params:
  - addressId: Mongo ObjectId

2.6) Cap nhat dia chi
- Method: PUT
- Endpoint: /api/users/addresses/:addressId
- Auth: User
- Params:
  - addressId: Mongo ObjectId
- Body:
  {
    "label": "Cong ty",
    "address": "Toa nha X",
    "isDefault": false
  }

2.7) Xoa dia chi
- Method: DELETE
- Endpoint: /api/users/addresses/:addressId
- Auth: User
- Params:
  - addressId: Mongo ObjectId

2.8) Lay danh sach dia chi
- Method: GET
- Endpoint: /api/users/addresses
- Auth: User
- Response (thanh cong):
  {
    "success": true,
    "message": "Lấy danh sách địa chỉ thành công",
    "data": [
      {
        "_id": "67c8a1b2...",
        "label": "Nha",
        "address": "123 Nguyen Trai, Q1",
        "isDefault": true
      },
      ...
    ],
    "meta": { "timestamp": "2026-04-22T10:00:00.000Z" }
  }

2.9) Xoa tai khoan cua chinh user (xoa mem)
- Method: DELETE
- Endpoint: /api/users/me
- Auth: User
- Dieu kien:
  - Khong co don hang nao o trang thai "Pending" hoac "Processing"
- Response (thanh cong):
  {
    "success": true,
    "message": "Tai khoan da duoc xoa (vo hieu hoa)",
    "data": null,
    "meta": { "timestamp": "2026-04-22T10:00:00.000Z" }
  }
- Ghi chu: Tai khoan bi set `isActive = false`, khong the dang nhap lai. Cac don hang cu van duoc giu nguyen.

8) INVENTORY APIs
Base public/user: /api/inventory
Base admin: /api/admin/inventory
=====================================================

Route grouping trong source code:
- Public/user inventory routes: server/routes/inventoryRoutes.js
- Admin inventory routes: server/routes/inventoryAdminRoutes.js

Ghi chu dong bo voi Swagger:
- Swagger JSON hien thi endpoint admin root duoi dang /api/admin/inventory/ vi route trong module duoc khai bao la '/'.
- Runtime endpoint de goi API van la /api/admin/inventory.
- Naming moi trong codebase: inventoryRoutes = public/user routes, inventoryAdminRoutes = admin routes.

8.1) Admin - Danh sach ton kho (co loc, phan trang)
- Method: GET
- Endpoint: /api/admin/inventory
- Swagger path: /api/admin/inventory/
- Auth: Admin
- Query optional:
  - productId (Mongo ObjectId)
  - lowStock (true/false, quy uoc lowStock = available < 10)
  - page (default 1)
  - limit (default 20)
- Response (format chuan he thong):
  {
    "success": true,
    "message": "Thành công",
    "data": [
      {
        "_id": "...",
        "sku": "SKU-001",
        "productId": {
          "_id": "...",
          "name": "Kinh A",
          "slug": "kinh-a"
        },
        "stock": 50,
        "reserved": 8,
        "available": 42,
        "warehouse": "main",
        "lastRestocked": "2026-04-19T10:00:00.000Z"
      }
    ],
    "meta": {
      "timestamp": "2026-04-19T10:30:00.000Z",
      "requestId": null,
      "totalInventories": 120,
      "currentPage": 1,
      "totalPages": 6,
      "limit": 20
    }
  }

8.2) User - Kiem tra ton kho truoc khi them vao gio
- Method: GET
- Endpoint: /api/inventory/check
- Auth: User
- Query required:
  - sku
  - quantity (so nguyen duong)
- Response (format chuan he thong):
  {
    "success": true,
    "message": "Thành công",
    "data": {
      "available": true,
      "currentStock": 50,
      "reserved": 8,
      "availableStock": 42,
      "requestedQuantity": 2,
      "sku": "SKU-001"
    },
    "meta": {
      "timestamp": "2026-04-19T10:30:00.000Z",
      "requestId": null
    }
  }

8.3) Admin - Chi tiet ton kho theo sku
- Method: GET
- Endpoint: /api/admin/inventory/:sku
- Auth: Admin
- Params:
  - sku: string (khong duoc rong)

8.4) Admin - Cap nhat ton kho theo sku
- Method: PUT
- Endpoint: /api/admin/inventory/:sku

9.9) San pham ban chay nhat
- Method: GET
- Endpoint: /api/admin/stats/top-products
- Auth: Admin
- Query optional:
  - limit: so san pham tra ve (default 10, toi da 50)
- Response (thanh cong):
  {
    "success": true,
    "message": "Thanh cong",
    "data": [
      {
        "_id": "...",
        "name": "Kinh Rayban A",
        "image": "https://...",
        "slug": "kinh-rayban-a",
        "isActive": true,
        "rating": { "avg": 4.5, "count": 12 },
        "totalSold": 85,
        "totalRevenue": 42500000
      },
      ...
    ],
    "meta": { "timestamp": "2026-04-29T10:00:00.000Z" }
  }
- Ghi chu:
  - Chi tinh tu don hang co status=Delivered
  - Sap xep theo totalSold giam dan
  - totalRevenue: tong doanh thu cua san pham do (items.price * quantity)
  - image: anh tu order item (snapshot luc mua, khong doi theo product)
  - slug, isActive, rating: lay tu collection products (lookup)
  - Neu san pham da bi xoa khoi DB, cac truong lookup se la null nhung van hien thi do lay name/image tu snapshot don hang

9.9) Thong ke tong quan (Dashboard)
- Method: GET
- Endpoint: /api/admin/stats/overview
- Auth: Admin
- Response (thanh cong):
  {
    "success": true,
    "message": "Thanh cong",
    "data": {
      "totalUsers": 120,
      "totalOrders": 340,
      "revenueThisMonth": 15800000,
      "lowStockCount": 7
    },
    "meta": { "timestamp": "2026-04-29T10:00:00.000Z" }
  }
- Ghi chu:
  - totalUsers: tong so tai khoan (ca active va inactive)
  - totalOrders: tong so don hang (tat ca trang thai)
  - revenueThisMonth: tong doanh thu cac don co status=Delivered trong thang hien tai (tinh theo createdAt)
  - lowStockCount: so luong SKU co available (stock - reserved) < 10
